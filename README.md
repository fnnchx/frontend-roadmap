# Book Catalog

## Description

Book Catalog is a small frontend application
for browsing, searching, and filtering books.

## Features

- browse books;
- search books;
- add books to favorites.

## Technologies

- HTML
- CSS
- JavaScript
- Vite
- npm

## Installation and Usage

git clone https://github.com/fnnchx/frontend-roadmap
cd book-catalog
npm install
npm run dev

## Production Build

npm run build
